## 💵 Finanse Tracker
This project is a  money tracker built in Python which enables to track personal expenses and forecast feature expenses by  a local AI model.


## ✨ Technologies

- `Python`
- `Pandas`
- `Rich`
- `sqlite3`
- `NeuralProphet`

## 🚀 Features

- `Track personal expenses`
- `forecast feature expenses`
- `Download data from local database to CSV file`
