## 💵 Finanse Tracker
This project is money tracker built in Python which enable track personal expenses and forecast feature expenses by local AI model.


## ✨ Technologies

-`Python`
-`Pandas`
-`Rich`
-`sqlite3`
-`NeuralProphet`

## 🚀 Features

-`Track personal expenses`
-`forecast feature expenses`
-`Download data from local database to CSV file`
